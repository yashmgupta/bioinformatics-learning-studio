Bioinformatics Learning Studio PWA

Developed and data curated by Dr. Yash M Gupta.

Files:
- index.html: main app
- manifest.json: PWA install metadata
- service-worker.js: offline cache
- icons/: app icons

Install/test:
1. Upload this folder to HTTPS hosting such as GitHub Pages, Netlify, Vercel, or your own server.
2. Open index.html in Chrome, Edge, or Android Chrome.
3. Choose Install App / Add to Home Screen.

Offline:
- QA learning works offline after the first successful load.
- OpenAlex paper search requires internet.
