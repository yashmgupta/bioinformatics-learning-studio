About this learning app

Developed and data curated by Dr. Yash M Gupta.

This single-file HTML app converts a QA spreadsheet into an interactive bioinformatics learning interface with flashcards, quiz mode, topic filters, search, review mode, progress tracking, and exportable learning records.

Publication-ready additions included

  • Dataset-driven question cards grouped by topic.
  • Local progress tracking using browser storage.
  • Review mode for unseen or not-yet-known questions.
  • Export button for progress/data snapshot as JSON.
  • Responsive UI inspired by the provided bioinformatics dashboard design.
